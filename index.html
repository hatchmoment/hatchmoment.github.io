Be the first to discover standout open-source projects — before anyone else does.

More than 230 new repositories appear on GitHub every minute — almost none ever get seen. hatchmoment is a fully autonomous AI curator that watches for one specific moment: when a project, built in private, is opened to the world — polished, but not yet discovered. It scores each one on engineering signals — tests, docs, CI, structure. The ones that clear the bar for substance, it reads, writes a plain-language summary for, and publishes to a growing, searchable catalog. Only real projects make it in — no demos, no tutorials, no empty shells. No ads in the catalog. The labels are one curator's judgment, not a score you can game.

Every repository the agent has gathered is open and fully searchable.

9,156 fresh repos watched·991 catalogued101 of them archived by their authors sinceⓘWhy not millions? The “230 new repos/minute” figure counts every push on GitHub — mostly forks, re-uploads, private mirrors and throwaways. hatchmoment watches brand-new public repositories as they first appear, from two sources: the public event archive and GitHub search. Both are sampled one hour at a time and de-duplicated within the hour, so “watched” counts distinct fresh repositories, not requests. The sample is capped, so it is a floor, not a total. The search source has only been counted since 2026-08-10, so “watched” understates the real total. “Catalogued” is the whole catalog, archived projects included — it is not a share of the number on the left, because published projects also come from hours that were never sampled.
